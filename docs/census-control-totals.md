## Обрывки областных данных из статей (не заменяют таблицу)

- Южный Казахстан (Вестник ЕНУ, по РГАЭ ф. 1562, оп. 336): всё население 1926 → 1939, тыс.: Алма-Атинская 726,7 → 798,7; Южно-Казахстанская 609,9 → 745,5; Жамбылская 322,5 → 321,6; Кызылординская 318,0 → 328,0. Доля казахов 1926 → 1939: 67,3 → 29,7 %; 70,1 → 46,9 %; 71,3 → 46,5 %; 87,3 → 61,0 %.
- Восточный Казахстан (ВКО + Семипалатинская; Аубакирова, Алексеенко, 2020): всё население 1027,0 → 916,8 тыс.; казахи 551,4 → 253,1 тыс. (53,7 → 27,6 %).
- Асылбеков и Асылбекова (2014): по текстовому описанию прирост общей численности 1926 → 1939 наибольший у Карагандинской области, убыль наибольшая у Павлодарской, Костанайской и Акмолинской; Жамбылская почти не изменилась.

## Что это означает для сайта (на 21.10.2026)

1. Сумма 12 областей на сайте для 1939 года: 4,78 млн всего и 1,82 млн казахов, против 6,15 млн и 2,33 млн по переписи: занижение примерно на 22 %.
2. Заявленная на сайте и в работе убыль казахов 51,4 % не совпадает с республиканской по переписям: 3,63–3,72 млн → 2,33 млн = −36…−37 %. Доля казахов в работе («>60 % → ≈38 %») совпадает с источниками: 3,63/6,07 ≈ 60 % и 2,33/6,15 = 37,8 %. Плашка сайта «69 % → 38 %» — неверна.
3. Данные сайта по Карагандинской области (общее население −6,7 %, потеря казахов 64,7 % — «максимум потерь») противоречат Асылбекову (у Карагандинской наибольший рост общей численности) и Алексеенко (Центральный район — наименьшие потери, 15,6 %). Нельзя утверждать «максимум потерь в Караганде», пока нет областной таблицы.
4. Для юга (Алма-Атинская, Южно-Казахстанская, Кзыл-Ординская) данные сайта показывают падение общей численности, а по архивным данным она росла.

## Чего не хватает

Полной таблицы «область × (всё население, казахи) × (1926, 1939)». Вероятные источники: Население Казахстана (2009), с. 57–62 и 340–357; РГАЭ, ф. 1562, оп. 336; Алексеенко А. Н. Население Казахстана в 1926–1939 годах (Барнаул, 2000). Также нужно проверить, в границах каких областей даны значения: перепись проводилась 17 января 1939 г., часть областей создана позже в 1939–1944 гг.
